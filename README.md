# Personal Journal

A simple command-line journal application built with Python.

## Features

- Write new journal entries.
- View all saved journal entries.
- Search journal entries for a specific word.
- Save entries in a local text file (`journal.txt`).

## Requirements

- Python 3 installed on your computer.

## How to Run

1. Open a terminal in the project folder.
2. Run the application:

   ```bash
   python main.py
   ```
